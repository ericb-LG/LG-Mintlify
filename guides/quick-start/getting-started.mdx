The Risk Cloud API is a collection of RESTful API endpoints that empower you and your team to
directly integrate, automate, and build with the Risk Cloud. JSON-based payloads are standard,
with certain endpoints supporting CSV and XLSX exports.

<Note>
API access requires purchasing the API Access Add-On Feature.
</Note>

## Authentication

Risk Cloud uses OAuth 2.0 for authentication, using a bearer Access Token in the `Authorization`
HTTP header. See [Authentication](/guides/api-usage/authentication) for how to obtain and manage
access tokens.

## Postman

A user-friendly Postman workspace makes it easy to build and refine integrations. See the
[Postman guide](/guides/quick-start/postman) for setup.

## Pagination

The API implements offset pagination so endpoints returning large datasets can be processed in
predictable chunks. See [Pagination](/guides/api-usage/pagination) for the full contract.

## Rate Limit

LogicGate recommends maintaining a rate limit of **10 requests per second** to ensure optimal and
efficient performance.
