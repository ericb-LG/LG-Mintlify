---
title: "Risk Cloud Webhooks"
description: "Use Risk Cloud Webhooks to push automation event data to external systems in real time."
---

Use Risk Cloud® Webhooks to enhance your custom integrations by sending event data to external
systems, so you can detect Risk Cloud events and perform custom operations in response.

Webhooks are created and managed from within Risk Cloud itself; see LogicGate's Help Center
article on setting up Risk Cloud Webhooks for configuration steps.

## Next steps

Once a webhook URL is configured, you can manage it programmatically with the
[Interacting with Webhooks via Endpoints](/guides/api-usage/risk-cloud-api-webhook-urls) API
guide, or continue to
[Risk Cloud PowerBI Connection](/guides/quick-start/risk-cloud-power-bi-connection) for another
way to get data out of Risk Cloud.
