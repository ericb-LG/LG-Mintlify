## Export Build Audit Log endpoint

The Build Audit Export endpoint returns a `.csv` or `.xlsx` file containing the Build Audits for the application given in the query parameters.

**`GET /api/v1/audit/build/export/{extension}`**

### Path parameter

| Parameter | Description |
|---|---|
| `extension` | The file format to export: `csv` or `xlsx`. |

### Query parameters

| Parameter | Required | Description |
|---|---|---|
| `applicationId` | Yes | The unique ID of the application to retrieve the build audit log for. Can be a previously deleted application's ID. |
| `startDate` | No | Inclusive start date, in `YYYY-MM-DD` format. |
| `endDate` | No | Exclusive end date, in `YYYY-MM-DD` format. |

### Response

The endpoint returns the requested file. To interpret its contents, see the "Reading the Log" section of the Build Audit Log help page and the Build Audit Log Glossary help page.
