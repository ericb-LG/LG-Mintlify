Roles correspond to functions within your organization's hierarchy (e.g. Compliance, Audit, IT
Operations) and can contain permission sets and entitlements that define the access of the
members of the role.

With the Risk Cloud API, role information — including associated entitlements, permission sets,
and users — can be exported for tracking access or aligning your role structure with external
systems.

Obtain your [API Access Token](/guides/api-usage/authentication) to get started. For more on
roles, refer to the Help Center articles on Creating Roles and Modular Entitlements for Roles.

## Retrieve Roles endpoint

The Roles API offers the following endpoint, which returns a list of all roles in the Risk Cloud
environment.

```
GET /api/v1/roles
```

### Response
