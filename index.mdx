The Risk Cloud API is a collection of RESTful endpoints that let you integrate, automate, and build with the Risk Cloud. This site combines the API usage guides that previously lived on the [LogicGate Developer Portal](https://www.logicgate.com/developer/) with a generated, always up-to-date reference for the public Risk Cloud API v2 spec.

## Start here

- **New to the API?** Start with [Getting Started](/guides/quick-start/getting-started), then [Authentication](/guides/api-usage/authentication) and [Postman](/guides/quick-start/postman).
- **Building a data sync?** See [Navigating Risk Cloud Data with API v2](/guides/api-usage/navigating-risk-cloud-data-with-v2) and [Pagination](/guides/api-usage/pagination).
- **Running many integrations?** See [Service Accounts](/guides/api-usage/service-accounts).

## API Reference

The [API v2 (Public) reference](/api-reference) covers every endpoint available to external integrators, generated directly from the [`openapi` repo](https://gitlab.logicgate.dev/eric.belisle/openapi) spec — this is the same spec published externally, so the reference here always matches what's live.

<Note>
  This portal only publishes the Public (v2) API reference. Internal, Legacy (v1), and Data Repositories API docs are not included here.
</Note>
