This reference covers the legacy Risk Cloud API v1 auth-and-identity endpoints — token
management, account details, external (record-scoped) users, and SCIM user/group provisioning.
It's grouped by resource in the sidebar.

<Note>
This is a partial v1 reference (auth/identity endpoints only), not the full legacy API. New
integrations should generally use [API v2](/api-reference) instead — v1 is documented here for
existing integrations that still depend on these endpoints.
</Note>
